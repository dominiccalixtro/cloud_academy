# Cloud Academy

Cloud Academy is a Cloud Engineering learning management system. The repository is an npm workspace containing the web application in `frontend/`.

## Commands

Run these commands from the repository root:

- `npm install` — install all workspace dependencies
- `npm run dev` — start the Vite development server
- `npm run lint` — lint the frontend
- `npm run test` — run unit tests
- `npm run build` — create the production build

## Repository layout

```text
frontend/       React, TypeScript, Vite application
docs/           Product and delivery documentation
.github/        Continuous integration and deployment workflows
```

See [frontend/README.md](frontend/README.md) for frontend architecture and local development details.
